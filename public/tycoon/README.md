# Original Nation Tycoon artwork

`buildings.png` and `upgrades.png` are original AI-generated isometric sprite atlases created for this project, using a consistent miniature architecture specification. They are not extracted from Township, Pocket City, or other reference games. Each atlas is a regular 4×4 sheet; Phaser computes frame boundaries from the actual image dimensions.

Buildings: town hall, cottage, farm, grocery, food factory, forestry, sawmill, mine, manufacturing, warehouse, depot, power, school, clinic, park, cargo terminal.

Upgrade atlas: four distinct visual stages for housing, grocery, farming, and manufacturing. Stages change at levels 6, 11, and 16. Other services gain a larger silhouette and tint as levels increase; they do not yet have unique architecture for every stage.
